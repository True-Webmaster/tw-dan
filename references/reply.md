# Reply: when the person comes back with records or corrections

They correct an assumption, answer an open question or send a record, in the same session or a new one (`update`, or naming the map). Open the JSON they named, or the most recently changed `tw-dan-*.json` in the current folder, and read it before anything else; if there is none, say so and build a fresh map from SKILL.md step 2. Keep the same file names and `date`; add to `revisions` today's date and one line on what moved.

1. **Decide what the new facts settle.** Any record may rule an explanation in or out, not only the evidence its `ruleOut` named; say which record in `evidence`. A ruled-out explanation stays in the file with `status: "ruled out"` and `likelihood: "unlikely"`, plus `probability: 0` when the map carries probabilities (then re-spread the rest to 100). Add the new facts to `facts` with their basis; settle an `isItReal` of "can't tell yet" if the records now can.
2. **If the front-runners named in summary line 1 changed, redo Decompose from the top:** new parts, new explanations (keep the ruled-out ones), new coverage test; on the thorough path, run the judge round again. If they did not change, edit in place and keep the existing `review`.
3. **Bring every other section into line** so the printed sequence still reads as one argument: summary, `confidence`, `restsOn`, blind spots (delete the ones the records covered and list them in `revisions`), abstract, reuse, streams, rubric (`pass` or `fail` only when the record meets the whole condition; partial evidence stays `unknown` with the evidence noted), tests, "it depends", assumptions, open questions, next action. New outside facts go through SKILL.md step 6. If records arrived and the map was at depth 1, you may go to depth 2.
4. **Build and open** as in SKILL.md steps 7 and 8, but the chat message is: when the front-runners changed, one line on what the records settled, then the usual message; otherwise one line on what changed and which explanation it ruled in or out, or that none did.
